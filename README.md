## ✨ Overview

This repository contains the source code for my personal 3D developer portfolio. Designed with a **premium monochrome aesthetic** and **cyan accents**, it combines interactive 3D elements with a seamless user experience to showcase my journey as a Fullstack Developer and AI Engineer.

## 🛠️ Tech Stack

- **Core**: [Next.js 15](https://nextjs.org/) (App Router)
- **3D Engine**: [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction) / [Three.js](https://threejs.org/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🌟 Key Features

- **Interactive 3D Environments**: Real-time WebGL backgrounds and models.
- **Dynamic Project Details**: Dedicated pages for each project with rich content rendering.
- **Glassmorphism UI**: A modern, sleek interface with blur effects and thin borders.
- **Gaming Modules**: Built-in interactive games (Space Shooter & Pong VIP) directly in the browser.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.
- **Performance Optimized**: Lazy-loaded 3D components and optimized assets for fast load times.

## 🕹️ Gaming Experiences

This portfolio isn't just for viewing—it's for playing. Check out the custom-built gaming modules:
- **/game**: Classic Space Shooter with high-speed combat.
- **/pong**: Pong VIP with AI-opponent logic.

## 🚀 Getting Started

### Prerequisites

- [Node.js 18+](https://nodejs.org/)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AhmadDiksa/diksa-s-3d-portfolio.git
   cd diksa-s-3d-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env.local` file in the root directory and add your API keys:
   ```env
   NEXT_PUBLIC_GEMINI_API_KEY=your_api_key_here
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
